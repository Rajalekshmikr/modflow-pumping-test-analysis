# Methodology

This project used a controlled synthetic groundwater-modelling approach to
investigate pumping-test interpretation under progressively less ideal aquifer
conditions.

## Overall Workflow

1. Establish the analytical Theis benchmark.
2. Develop a homogeneous confined-aquifer MODFLOW 6 baseline model.
3. Evaluate model-domain size and boundary effects.
4. Investigate pumping-duration sensitivity.
5. Introduce controlled vertical heterogeneity using H0, H1 and H2 scenarios.
6. Estimate transmissivity and storativity using Direct Theis and Cooper–Jacob.
7. Evaluate agreement using RMSE, relative error and parameter bias.
8. Reconstruct equivalent numerical models using FloPy to assess computational reproducibility.

## Baseline Aquifer

The synthetic confined aquifer used:

- Aquifer thickness: 20 m
- Hydraulic conductivity: 8.64 m/day
- Reference transmissivity: 172.8 m²/day
- Specific storage: 1 × 10⁻⁵ 1/m
- Reference storativity: 2 × 10⁻⁴
- Pumping rate: 50 m³/day
- Initial hydraulic head: 10 m
- Simulation duration: 10 days

Observation locations were positioned at:

50 m, 100 m, 200 m, 500 m and 1000 m from the pumping well.

## Analytical Methods

### Theis Solution

The analytical Theis solution was used as the primary benchmark for ideal
confined-aquifer behaviour.

### Cooper–Jacob Method

The Cooper–Jacob straight-line approximation was used for transmissivity and
storativity estimation within an appropriate late-time validity range.

## Numerical Modelling

MODFLOW 6 simulations were developed using ModelMuse.

Controlled experiments investigated:

- model-domain size
- no-flow boundaries
- constant-head boundaries
- general-head boundaries
- pumping-duration sensitivity
- vertical hydraulic-conductivity heterogeneity

## Parameter Recovery

Hydraulic heads generated by MODFLOW were converted to drawdown.

Transmissivity and storativity were subsequently estimated using:

- Direct Theis nonlinear fitting
- Cooper–Jacob straight-line analysis

## Evaluation Metrics

Model and analytical agreement were evaluated using:

- Root Mean Square Error (RMSE)
- Relative error
- Parameter bias
- Semi-logarithmic drawdown behaviour

## Reproducibility

Equivalent H0, H1 and H2 MODFLOW 6 models were reconstructed programmatically
using FloPy and their outputs compared with the corresponding ModelMuse simulations.
